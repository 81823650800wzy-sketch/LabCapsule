# LabCapsule Android Remote 0.5.0

原生 Java Android 8.0+ 控制器，不依赖 Gradle 或第三方运行库。界面默认中文，采用五分区透明液态滚轮导航：首页、实验、数据、AI、设置。连接、屏幕、壁纸、GIF 和固件均属于设置，三个设置组默认折叠。

应用使用原创工业街机视觉系统：高对比警示色、信息标签、斜线底纹和透明控制甲板。它与设备端 ST7789 使用同一套三色预设和信息层级，不包含第三方游戏的 logo、角色或素材。

## 功能

- 首页包含桌面振动、碰撞峰值、姿态稳定快捷实验；实验页支持自定义参数、协议查看、开始/停止/中止和 I²C 扫描。
- 数据页保留最近 50 条实验元数据，可导入串口 CSV 或通过 BLE/HTTP 同步设备离线缓存，并计算六轴 RMS、Peak、FFT 主频，也可分享摘要。
- BLE 在线实验直接接收紧凑六轴通知并保存到应用私有 CSV；没有在线接收端时设备自行缓存，稍后可在“数据 → 设备离线缓存”读取、同步、分析或清空。
- 局域网 HTTP 与 Bluetooth LE 两种设备通道；传输选择在各设置区保持同步。
- 屏幕主页/设置/开发诊断/彩条/壁纸/反色/背光/方向键/确认/中止遥控。
- JPG、PNG、WebP 和 GIF 必须先在触控编辑器中拖动/缩放并确认 3:4 裁剪，原始大文件不发送给设备。
- 静态图片在手机端缩放并选择 RGB565/RLE565；GIF 在手机端一次性预处理为基准帧和稀疏 `delta332` 循环帧，未变化帧跳过。
- 图片可经 Wi-Fi 或 BLE 显示；壁纸写入专用分区并成为设备所有页面底层。GIF 缓存只存于 APK 私有目录，由前台服务循环发送，ESP32 不保存 GIF。
- 完成预处理后关闭或从最近任务划掉 APK，GIF 仍继续播放；系统通知显示状态并提供“停止”。Android 系统设置中的“强行停止”仍会终止服务。
- 内置街机黄黑、信号红灰、冷蓝录像三套预设；四条 0–100 滑杆直接调整壁纸、设备面板、设备 HUD 和 APK 玻璃层透明度。
- 传感器扫描和状态查询；I²C 扫描可完全通过 BLE 完成；Wi-Fi/BLE 双通道 OTA。
- 外部 Wi-Fi、恢复热点、亮度及 mqtt/mqtts 远程参数配置；设备页直接显示“未配置 / 连接中或失败 / 已连接”和可点击使用的局域网 IP。
- BLE 一键配网不会切换手机 Wi-Fi；状态卡直接显示 `staConnected`、`staIp`、恢复热点和常见失败原因。
- 网络区明确标注 ESP32-S3 只支持 2.4 GHz。纯 5 GHz 环境下可保持 BLE 使用实验、I²C 扫描、控制、媒体和离线同步，不要求手机加入无互联网热点。
- 240×320 实时屏幕状态镜像同步设备页面、状态、I²C、背光和 HUD，不持续搬运大帧缓冲。
- OpenAI 兼容 AI 配置，默认 DeepSeek；协议字段和设备安全范围校验，AI 失败时本地回退。
- 启动时检查 GitHub Releases；可下载 APK 和 OTA bin。

敏感字段通过 Android Keystore AES/GCM 加密。API Key 不发送给 ESP32。

## 构建

需要本机 Android SDK Build Tools。运行：

```powershell
cd <仓库目录>\android
.\build-apk.ps1
```

输出：`dist/LabCapsule-0.5.0.apk`。脚本会完成资源编译、Java 编译、DEX、APK 对齐、签名及签名验证。开发签名文件位于本机并被 `.gitignore` 排除。

## 初次连接

### 推荐：BLE 一键配网

1. 手机保持连接正常、有互联网的 Wi-Fi。
2. 在“设置 → 设备与连接”扫描 BLE，连接后点击“蓝牙一键配网”。
3. 输入 2.4 GHz SSID/密码；APK 自动轮询 `staConnected` 和 `staIp`。
4. 成功后点击“使用此局域网 IP”。完整说明可直接从 APK 打开 GitHub 文档。

### 恢复热点

1. 手机连接 `LabCapsule-XXXX`，密码 `labcapsule`。
2. APK 的设备地址使用 `http://192.168.4.1`。
3. 在“设置 → 设备与连接”配置外部 2.4 GHz Wi-Fi，等待“外部 Wi-Fi 状态”显示已连接。
4. 看到 `局域网 IP：http://...` 后点击“使用此局域网 IP”，再让手机切回原有互联网 Wi-Fi。

若只显示“已保存配置，正在连接或连接失败”，表示固件中的 `staConfigured=true`、`staConnected=false`；请检查 2.4 GHz、SSID 和密码。APK 已把原始 JSON 状态翻译为明确中文，无需手工查找字段。

ESP32-S3 的 Wi-Fi 射频不支持 5 GHz。若现有路由器只有 5 GHz，`staConnected=false` 与 `staIp=0.0.0.0` 属于预期结果，不是 APK 配网失败；直接保留 BLE，或以后增加 2.4 GHz/双频接入点即可。不要为了使用本应用让手机长期连接无网络的恢复热点。

### BLE 其他功能

点击“扫描 BLE”，允许 Android 12+ 的附近设备权限。BLE 适用于配网、I²C 扫描、控制、状态、图片、壁纸和 OTA。GIF 默认约 5.5 fps 并采用稀疏差分；大量、高帧率或大面积变化的媒体仍优先使用局域网。

## 图片与 GIF

1. 展开“设置 → 屏幕、壁纸与 GIF”，点击“选择并裁剪”，选取 JPG、PNG、WebP 或 GIF。
2. 在白色 3:4 框内拖动图片，双指缩放；点击“确认裁剪”后才能发送。
3. “显示图片”保留 RGB565 色彩并自动尝试 RLE565；“保存壁纸”固定使用完整 RGB565 写入持久分区。
4. “后台播放 GIF”会先完成一次裁剪、抽帧、RGB332 量化及最小编码选择。Wi-Fi 目标约 11 fps，BLE 目标约 5.5 fps，最长分别缓存 240/120 帧；实际速度受图案复杂度和链路影响。
5. 基准帧使用 RGB332/RLE332；循环帧会在 `delta332`、RLE332 和 RGB332 中选择更小的负载。`delta332` 只包含跳过长度和连续变化像素。
6. 等待提示“后台 GIF 已启动”即可退出 APK；即使在预处理中划掉界面，前台服务也会让当前预处理任务完成并自动接管。播放文件位于应用私有目录，替换 GIF 时自动覆盖，不写入 ESP32 Flash。

壁纸预览中的 LC 标识、状态卡和传感器文字属于 HUD 合成预览，不会烘焙进上传的 RGB565 壁纸。设备在显示主页、设置、诊断和 GIF 时按当前透明度实时叠加同构 HUD。

图片边界解码会把采样倍率限制为至少 1，避免 `divide by zero`。屏幕预览的测量比例固定为 240:320；实时监看使用设备状态驱动同构渲染。由于 ST7789 是只写 SPI，它不是面板像素回读。

## 实验与数据

- 首页快捷实验与 AI 协议都会进入同一执行路径并登记本机记录。
- 实验页的采样率范围为 10–500 Hz，时长为 1–3600 秒。
- 数据页导入文本或 CSV；支持 `DATA,timestamp_us,ax,ay,az,gx,gy,gz` 和不带 `DATA` 前缀的七列格式。
- 分析最多读取 100,000 行；FFT 使用最多 4,096 个点和 Hann 窗。时间戳按微秒估计采样率。
- “读取状态”显示设备离线会话数、样本数和容量；“同步并分析”通过当前 BLE 或局域网通道导出 `LCB1`，在手机端转换成 CSV 后执行分析。BLE 同步期间保持设备连接，成功确认文件后再按需清空设备缓存。

## AI 协议

接受的 JSON 至少包含：

```json
{
  "name": "不同材料振动衰减",
  "sample_rate_hz": 200,
  "duration_seconds": 20,
  "groups": ["对照组", "泡棉组"],
  "analysis": ["RMS", "Peak", "FFT"]
}
```

采样率允许 10–500 Hz，时长允许 1–3600 秒。点击“发送并开始实验”后，Wi-Fi 使用 `/api/experiment`，BLE 使用 `START:<rate>:<duration>`。

## 在线更新限制

应用使用 GitHub Releases API 查找 `.apk` 和文件名含 `ota` 的 `.bin`。固件可在应用内更新；APK 下载完成后由 Android 系统安装器显示确认，普通应用不能静默替换自身。
