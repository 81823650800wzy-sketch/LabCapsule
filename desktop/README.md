# LabCapsule Studio V0.11.0

Windows 桌面伴侣通过 CH343 / USB Serial 连接设备，不会切换电脑 Wi-Fi，也不会连接设备的无网络热点。V0.11.0 在统一桌宠角色包之上加入 COM8 实体桌宠独立界面、中文对话气泡、电脑/实验上下文 AI、受限 Claude 复杂任务转交和 Live2D 动作联动；Android V0.7 继续兼容使用。

## 主要能力

- 数据线连接后每 2 秒发送 CPU、内存、磁盘和温度，设备自动进入闲置硬件仪表界面；开始实验时自动切回实验界面。
- 读取 Windows 通知并镜像到屏幕（首次需 Windows 授权；缺少 `winsdk` 时仍可手动推送通知）。
- 以真实 `240 × 320` 比例预览图片、GIF、视频和透明桌宠；支持 0.25–8 倍缩放、平移、适应/填充及黑/白补底。
- 电脑承担视频解码、缩放、合成和 RGB332 差分压缩；设备只保存一个当前壁纸或动画，上传结束后自主播放。
- 1–8 FPS 明确帧率控制；上限依据当前 ST7789 10 MHz 稳定总线的整屏能力，不使用百分比速度。
- 实时接收 AX/AY/AZ、GX/GY/GZ 与两种模长。加速度和角速度使用独立 Y 轴；鼠标悬停读取真实时间戳和坐标，滚轮缩放时间轴，`Ctrl + 滚轮`缩放 Y 轴，拖动平移，双击复位。
- 最多保留 100,000 个实时点；绘制时按屏幕像素做保峰值抽稀、约 30 FPS 合并重绘，原始样本仍可导出 UTF-8 CSV。
- AI 桌宠具有角色设定、设备与电脑上下文、实验事件反应、本地记忆、桌面悬浮层和离线回退。OpenAI 兼容 Endpoint/模型可配置，DeepSeek 官方 Endpoint 默认使用 `deepseek-v4-flash`。
- 用户显式打开实体桌宠页后，安全回答会排版为 `216 × 64` 中文位图气泡并同步到 ST7789；设备本地执行 IDLE/TALK/THINK/ALERT 等白名单动作，不传桌宠视频。
- 复杂实验设计可转交本机 Claude Code；转交进程禁用全部工具、浏览器、MCP 与会话持久化，并限制为单轮只读和固定预算，不能直接控制设备。
- AI 桌宠可下载 HTTPS PNG/JPG/WebP/GIF；内置四个 DiceBear CC0 预设，完成限流、尺寸/帧数、格式、哈希、单份缓存和失败回滚检查。
- AI 桌宠可直接选择含 `pet.json` 的角色包或桌宠库；同一主形象、名称、人格和欢迎语同步到主舞台、悬浮层与屏幕工作室，重启后重新校验并恢复。
- AI 桌宠可直接识别 Cubism `model3.json` 运行时文件夹，校验依赖后在 WebView2/WebGL 主舞台或透明置顶悬浮舞台播放真实动作。首次运行必须由用户确认适用的 Live2D/Cubism 条款。
- 网络形象同步到主舞台与悬浮层；GIF 按源文件逐帧延时播放。当前形象可载入屏幕工作室，仍由用户确认 240×320 裁剪和 USB 上传。
- API Key 使用当前 Windows 用户的 DPAPI 加密；模型不具备系统命令权限，开始/中止实验、改网络和更新固件不能由模型直接执行。
- 屏幕主页、设置、开发诊断、色卡、背光、反色和三层透明度可视化控制。

V0.11 完整安装和测试见 [实体桌宠、AI 与 Claude 使用手册](../docs/V0.11.0_DEVICE_PET_AI_CLAUDE_ZH.md) 与 [测试记录](../docs/V0.11.0_TEST_REPORT_ZH.md)；角色包制作见 [V0.10.0 统一桌宠测试手册](../docs/V0.10.0_UNIFIED_PET_PACKAGE_TEST_ZH.md)；网络形象与通用网址见 [V0.9.0 网络形象指南](../docs/V0.9.0_NETWORK_AVATAR_GUIDE_ZH.md)。

## 运行

在 PowerShell 中：

```powershell
cd <仓库目录>\desktop
.\run.ps1
```

串口固定为 `460800 8N1`。应用优先选择 COM8，但仍显示完整端口列表供用户确认。

## 图表操作

1. 进入“实验与数据”，勾选需要观察的通道；加速度单位为 `g`，角速度单位为 `°/s`。
2. 移动鼠标到曲线，十字线会吸附到最近的真实样本，同时显示横坐标、设备微秒时间戳、通道、纵坐标和单位。
3. 滚轮以鼠标位置为中心缩放时间轴；按住 `Ctrl` 滚轮缩放数值轴；按住左键拖动平移。
4. 手动缩放后会暂停实时跟随；双击图表或点击“复位视图”恢复实时跟随与自动 Y 轴。
5. 窗口可选 2/5/10/30/60 秒或全部；导出 CSV 不受当前显示窗口和通道开关影响。

## AI 桌宠操作

1. 进入“AI 桌宠”，填写 OpenAI 兼容 Endpoint、模型和 API Key，也可不填 Key 使用本地规则回退。
2. 角色会读取连接状态、实验状态、最新六轴样本、有界统计摘要以及系统资源摘要；不会读取任意屏幕或用户文件。
3. “保存最近对话与用户偏好”只在本机保存最多 40 条消息和 20 条短偏好，可一键清除。
4. 点击“在 COM8 打开桌宠界面”后，安全回答会同步为固定尺寸中文气泡；实验采集中自动停止同步，避免影响实时数据链路。连接本身不会擅自切换设备页面。
5. 点击“显示桌面悬浮宠物”打开轻量悬浮层；拖动移动，双击返回主窗口，右键隐藏。
6. 点击“统一桌宠管理”，选择一个角色包或桌宠库并应用；也可选择 DiceBear CC0 预设或粘贴图片直链。角色包统一名称、人格和主形象；公网素材只接受 HTTPS，最大 12 MiB、2048²、120 帧。
7. 选择 Live2D 包时，首次由用户本人确认适用条款；随后“打开 Live2D 舞台”显示动作按钮，“显示桌面悬浮宠物”打开透明置顶舞台。底部必须显示 `WebGL 就绪`，关闭主应用会收尾其子窗口。
8. 勾选“复杂任务自动转交本机 Claude”后，只有多阶段设计/详细分析类请求会进入受限子流程；开始/停止实验、网络和固件操作始终需要用户在专用页面确认。

## 打包 EXE

```powershell
cd <仓库目录>\desktop
.\build-windows.ps1
```

桌面端媒体上传仍使用 `UPLOAD,CLIP|WALLPAPER,SIZE,CRC32`。固件写入临时文件、校验 CRC 与 LCG 容器，再原子替换旧媒体，断电不会留下半个新文件。
