## 本轮修复的两个启动根因

1. Pixi 6 的默认着色器统一变量同步路径会使用 `new Function`，与播放器的严格 CSP 冲突。现已加入同版本 `@pixi/unsafe-eval` 的静态 setter 实现；这个包名表示替代不允许 eval 的环境，并不要求放宽 CSP。
2. 原生关闭桥接曾把 pywebview `Window` 保存为公开 `js_api` 属性，导致其递归导出 Windows `AccessibilityObject`。现把窗口引用保存在 JS API 外部，只向网页暴露 `close_player()`。
