# LabCapsule V0.11.0 全面测试记录

测试日期：2026-08-31。硬件为 COM8 的 ESP32-S3 rev 0.2、16 MiB Flash、8 MiB PSRAM、ST7789 240×320 和 MPU6050 0x68；电脑为 Windows 11、Python 3.12、ESP-IDF 5.5.4。

## 结论

V0.11 的实体桌宠独立界面、中文气泡、动作白名单、电脑/实验上下文 AI、本机 Claude 受限转交、Hiyori Live2D 动作联动、自动串口握手及最终 EXE 均完成实机验证。测试期间没有连接设备的无网络热点，没有启动实验，没有删除原有壁纸或离线实验。

## 已知边界

- 当前实体屏角色为固件轻量形象；moc3 仅在电脑端 GPU 舞台运行。
- Android V0.7 与 V0.11 固件继续兼容，但完整 V0.11 AI 桌宠 UI 是后续手机端工作。
- ESP32-S3 Wi-Fi Station 仍只支持 2.4 GHz；纯 5 GHz 网络会保持 `staConnected=false / staIp=0.0.0.0`，USB/BLE/离线实验不受影响。
- EXE 未做 Authenticode 签名，Windows 可能显示未知发布者；应从 GitHub Release 获取并校验 SHA-256。
