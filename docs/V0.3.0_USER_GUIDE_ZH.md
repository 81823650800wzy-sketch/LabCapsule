# LabCapsule V0.3.0 中文使用指南

## 1. 上电检查

使用数据 USB-C 连接 ESP32-S3。Windows 设备管理器应显示 CH343 串口；本次实机为 COM8。串口参数为 460800 baud。

正常日志至少包含：

```text
BOOT,LABCAPSULE,0.3.0-alpha
OK,DISPLAY,ST7789,SPI=10MHZ
OK,CONNECTIVITY,WIFI=192.168.4.1,BLE=READY
READY,TYPE=PING_OR_HELP
```

若出现 `MPU6050_NOT_FOUND`，检查 MPU6050 的 3V3、GND、SDA GPIO8、SCL GPIO9，尤其确认共地和 SDA/SCL 没有接反。INT GPIO2 在第一阶段可不接。

## 2. 安装 APK

将 `release/LabCapsule-0.3.0.apk` 传到 Android 8.0+ 手机，允许浏览器或文件管理器安装未知来源应用，然后安装。应用只在使用 BLE 时申请附近设备权限。

## 3. 首次通过恢复热点连接

1. 手机 Wi-Fi 连接 `LabCapsule-XXXX`，密码 `labcapsule`。
2. Android 可能提示“此网络无法访问互联网”，此时临时选择保持连接。
3. 打开 LabCapsule，在“设备”页保持地址 `http://192.168.4.1`。
4. 点击“连接/刷新状态”。

这一步只用于初次配置或恢复，不需要作为日常使用方式。

## 4. 接入外部 Wi-Fi

1. 保持连接恢复热点，进入“设置”。
2. 填写家庭/实验室 2.4 GHz Wi-Fi 的 SSID 与密码。
3. 建议保留“LabCapsule 恢复热点”，点击“保存并连接”。
4. 回到设备页刷新状态，找到 `network.staConnected:true` 和 `staIp`。
5. 手机切回原来有互联网的 Wi-Fi。
6. 将设备地址改为 `http://staIp`，例如 `http://192.168.1.86`，再次刷新。

设备只支持 ESP32-S3 的 2.4 GHz Wi-Fi。若连接失败，可重新进入恢复热点修改配置。

## 5. BLE 连接与文件传输

在“设备”选择 Bluetooth LE，点击扫描连接并授权。连接成功后可以遥控屏幕、传输图片/壁纸和执行 OTA。BLE 分片大小会根据协商 MTU 自动调整，媒体使用 CRC32 完整性校验。

Wi-Fi 更适合 GIF 和固件等大文件；BLE 适合不方便切换网络时的控制和救援更新。

## 6. 屏幕和 GIF

1. 在“屏幕”选择 JPG、PNG、WebP 或 GIF。
2. “显示单帧”只把一帧送入 PSRAM，不写 Flash。
3. “保存壁纸”写入设备专用壁纸分区并持久保留。
4. “播放 GIF”由手机持续解码和传输；停止播放后 ESP32 不保存 GIF 原文件。

固件使用 PSRAM 双帧缓冲和 8 行 DMA 呈现块，不会在每次刷新前主动清成黑屏。

## 7. AI 实验

1. 确保手机已回到可访问互联网的 Wi-Fi/移动网络，同时设备在同一局域网或 BLE 已连接。
2. 在“AI”填写 OpenAI 兼容 Endpoint、模型名和 API Key。默认值适配 DeepSeek。
3. 输入问题，例如“比较泡棉和橡胶垫上的振动衰减”。
4. 点击生成协议，检查名称、10–500 Hz 采样率、1–3600 秒时长、实验组和分析方法。
5. 点击“发送并开始实验”。

AI 服务失败或返回无效 JSON 时，应用自动给出 200 Hz、20 秒、RMS/Peak/FFT 的本地对照模板。Key 只保存在手机的 Android Keystore 中。

## 8. 远程 MQTT

在“设置”填写 mqtts Broker URI、用户、密码和主题前缀，启用远程连接。设备上线后：

```text
向 <前缀>/<设备ID>/command 发布 home、developer、test、brightness_50 等命令
从 <前缀>/<设备ID>/status 接收状态和执行结果
```

生产部署应使用 mqtts、独立设备账号和最小 ACL。不要把设备本地 HTTP 端口直接映射到公网。

## 9. 固件和 APK 更新

- 固件：在“实验”选择 OTA bin 或下载最新固件，再选择 Wi-Fi/BLE 开始 OTA。
- APK：应用启动时可自动检查 GitHub Release；下载完成后点击系统通知安装。
- Android 要求用户确认 APK 安装，这是系统安全限制。
- 0.1.x 首次升级到新分区表必须用 USB 完整烧录，不能只发送 OTA bin。

## 10. 开发诊断

屏幕页点击“开发诊断”，或串口发送 `DISPLAY,DEV`。诊断信息会给出 ST7789 固定线路：

```text
SCK=12 MOSI=11 CS=10 DC=7 RST=6 BL=5 VCC=3V3 GND=COMMON
```

- 完全无背光：先查 3V3、GND、BL(GPIO5)。
- 有背光但全白：查 SCK、MOSI、CS、DC、RST，确认模块为 ST7789 240×320。
- 图像错色：使用“颜色反转”与彩条测试。
- 串口显示 `DISPLAY=READY` 只代表 ESP32 SPI 发送成功；ST7789 接线没有 MISO，固件无法读取面板确认。
