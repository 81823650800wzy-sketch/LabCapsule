# LabCapsule V0.3.2 壁纸与界面指南

## 设计目标

V0.3.2 不再把上传素材当成一个孤立的“图片页面”。静态素材写入壁纸分区后，成为主页、设置和开发诊断界面的底层；临时图片和 GIF 进入独立 PSRAM 媒体画布，也会在每帧上重新合成设备 HUD。

APK 与 ST7789 共用原创工业街机视觉语言：高对比警示色、斜线标记、模块化信息卡、短促状态标签和深色半透明控制甲板。参考的是成熟都市街机界面的高层设计方法，不复制第三方 logo、角色、美术素材或具体版式。

## 三套预设

- 街机黄黑：米白文字、警示黄主色、信号红点缀，默认预设。
- 信号红灰：红色主控、黄色辅助，适合报警或实验中状态。
- 冷蓝录像：青色主控、荧光绿辅助，适合仪器和监测场景。

切换预设后，APK 当前页面、液态滚轮导航、壁纸合成预览和设备屏幕会使用同一组颜色。

## 四条连续透明度

在 APK“屏幕与壁纸 → 界面混合台”中可直接拖动：

1. 壁纸可见度：控制持久/动态壁纸与主题底色之间的混合，0 为不显示壁纸，100 为完整壁纸。
2. 设备面板遮罩：控制设备信息卡的深色遮罩，0 为全透明，100 为实色面板。
3. 设备 HUD / 文字：控制标记、分隔条和文字，0 为隐藏，100 为完整显示。
4. APK 面板 / 导航玻璃：只影响手机端卡片和底部导航，0–100 连续生效。

前三项会在拖动过程中以 220 ms 防抖节奏同步，避免连续网络请求压垮 ESP32；预览每次进度变化都立即刷新。也可点击“立即同步到设备”确认结果。

## 壁纸上传流程

1. 点击“选择并裁剪”，在白色 3:4 框内拖动和双指缩放。
2. 确认后看到的是“壁纸 + HUD”合成预览；HUD 只用于预览，不会写进原始壁纸。
3. 点击“设为设备壁纸”。APK 仅发送 240×320 RGB565 成品，不上传原始大图。
4. 固件完成双槽 CRC 提交后回到主页，并使用当前透明度合成壁纸。

“临时单帧”用于不写 Flash 的快速试画，但显示时同样作为动态背景叠加 HUD。

## GIF 动态壁纸

GIF 文件和解码仍留在手机。APK 逐帧裁剪、RGB332 量化、比较变化矩形并选择 RLE；固件只把差分写入独立 PSRAM 媒体画布，再把主页 HUD 合成到当前显示帧。这样既降低传输量，也不会把旧 HUD 像素带入下一帧。

## 通道

- Wi-Fi：`POST /api/display` 保存外观，`POST /api/wallpaper` 保存壁纸。
- BLE：`STYLE:preset:wall:panel:hud` 和既有 WALLPAPER 分片通道。
- USB：`STYLE,preset,wall,panel,hud` 用于开发验证；串口命令只即时应用，APK 的 HTTP/BLE 设置会写入 NVS。
