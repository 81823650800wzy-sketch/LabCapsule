# LabCapsule V0.3.3 蓝牙配网与连接排障

本指南对应 APK 与固件 V0.3.3。推荐方式是让手机始终连接有互联网的正常 Wi‑Fi，只用 Bluetooth LE 给 LabCapsule 下发路由器信息。手机不需要连接 `LabCapsule-XXXX`，因此不会因“此 Wi‑Fi 无互联网”而断网。

## 最短连接流程

1. 给 LabCapsule 通电，打开 APK 的“设备”页。
2. 点击“扫描 BLE”，允许 Android 的“附近设备”权限，等待提示“BLE 控制、配网、I²C 扫描与媒体通道已就绪”。
3. 点击“蓝牙一键配网”。
4. 输入路由器的 **2.4 GHz** SSID 和密码。SSID 区分大小写；开放网络的密码可留空。
5. 点击“保存并连接”。APK 会在约 2、5、9 秒读取连接结果。
6. 状态卡显示 `staConnected=true` 和非 `0.0.0.0` 的 `staIp` 后，点击“使用此局域网 IP”。之后图片、固件和 GIF 可优先使用速度更快的局域网通道。

## 如何判断成功

成功时 APK 会明确显示：

```text
● 已连接外部 Wi‑Fi
局域网 IP：http://192.168.x.x
staConnected=true · staIp=192.168.x.x
```

未成功时会显示 `staConnected=false`、`staIp=0.0.0.0` 和最近一次断开原因。常见代码：

- 201：没有找到输入的 2.4 GHz 网络。检查 SSID、距离，并确认路由器没有只开启 5 GHz。
- 202：密码或认证失败。
- 203：路由器拒绝关联，检查黑名单、接入数量或加密兼容性。
- 204：握手超时，靠近路由器后重试。

ESP32-S3 不支持 5 GHz。双频路由器可使用同名 2.4/5 GHz，但必须确保 2.4 GHz 频段已开启；纯 5 GHz SSID 无法连接。

## 找不到设备热点

V0.3.3 会在外部 Wi‑Fi 连续失败四次后停止无效重连，自动退回纯恢复热点模式。热点参数为：

```text
SSID：LabCapsule-XXXX
密码：labcapsule
地址：http://192.168.4.1
```

若仍未看到热点，但 BLE 已连接，点击 APK 的“恢复设备热点”。该操作通过 BLE 执行，不会切换手机网络。然后等待约 2 秒并刷新手机 Wi‑Fi 列表。

恢复热点只是应急入口。日常使用仍推荐 BLE 配网后改用局域网 IP，无需让手机停留在无互联网热点。

## 只有 BLE 时扫描传感器

1. 在“设备”页连接 BLE，APK 会自动选择 Bluetooth LE 通道。
2. 打开“实验”页，点击“扫描传感器”。
3. 固件会直接扫描 SDA GPIO8 / SCL GPIO9，并通过 BLE 返回发现数量、名称和地址。

若发现数量为 0，请检查 3V3、GND 共地、SDA=GPIO8、SCL=GPIO9。地址有响应只表示总线上存在设备；例如 MPU 系列仍需结合 `WHO_AM_I` 确认具体型号。

## 屏幕实时镜像

“屏幕”页的预览严格保持 240×320（3:4）比例。点击“开始实时监看”后，APK 每秒读取设备的当前页面、实验状态、I²C 状态、背光状态和透明度，并在本机壁纸上重建同构 HUD。

ST7789 使用只写 SPI，硬件没有接回读线，因此这不是面板像素采集；它是由设备固件状态驱动的实时渲染镜像。这样不会持续传输 153,600 字节帧缓冲，也不会挤占 BLE 图片/GIF 和传感器链路。

## 图片出现 `divide by zero`

V0.3.3 已修复图片边界解码时采样倍率未初始化的问题，并在尺寸无效时提前返回明确错误。更新 APK 后重新选择文件并完成 3:4 裁剪即可。GIF 仍由手机裁剪、解码、量化和差分压缩，ESP32 不保存 GIF 文件。

## 仍无法连接时

请依次确认：

1. APK 与设备固件都显示 V0.3.3；旧 APK 无法发送 BLE 配网/传感器命令。
2. Android 已授予“附近设备”权限，BLE 页面显示已就绪。
3. SSID 是 2.4 GHz 且区分大小写，密码长度不超过 63 字节。
4. 路由器没有启用仅 WPA3、企业认证、网页登录或设备白名单。
5. 点击“恢复设备热点”确认 `LabCapsule-XXXX` 能重新出现。
6. 通过 USB 串口 460800 baud 读取启动与 Wi‑Fi 断开日志。
