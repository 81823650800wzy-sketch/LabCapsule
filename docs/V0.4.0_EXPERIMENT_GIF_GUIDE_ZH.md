# LabCapsule V0.4.0 实验、数据与后台 GIF 指南

V0.4.0 把 APK 从“设备设置工具”重构为实验入口。底部导航固定为：首页、实验、数据、AI、设置。设备连接、屏幕、壁纸、GIF 和固件维护都在“设置”中，且默认折叠，不再占用主功能入口。

## 1. 首次连接

1. 手机保持连接家中或实验室原有的联网 Wi-Fi，不要连接 LabCapsule 的无网络热点。
2. 打开“设置”，展开“设备与连接”。
3. 点击“扫描 BLE”，连接 `LabCapsule-XXXX`。
4. 若尚未配网，点击“蓝牙一键配网”，输入 2.4 GHz 路由器 SSID 和密码。
5. 等待卡片明确显示“外部 Wi-Fi 已连接”及 `staIp`，再点击“使用局域网 IP”。

只有排障时才需要恢复热点 `LabCapsule-XXXX`（密码 `labcapsule`，地址 `http://192.168.4.1`）。完整配网排障见 [V0.3.3 蓝牙配网与连接排障](V0.3.3_BLE_WIFI_QUICKSTART_ZH.md)。

## 2. 运行实验

首页可直接启动三类预设：

| 预设 | 采样率 | 时长 | 适用场景 |
|---|---:|---:|---|
| 桌面振动 | 200 Hz | 20 s | 比较材料或结构的振动 |
| 碰撞峰值 | 500 Hz | 8 s | 捕捉短时冲击峰值 |
| 姿态稳定 | 100 Hz | 30 s | 观察姿态和慢速运动 |

“实验”页可输入 10–500 Hz 采样率和 1–3600 秒时长，也可扫描 I²C 传感器。首页、实验页和 AI 页最终都走同一个 Experiment Protocol 下发路径，并自动在“数据”页登记实验名称、参数和时间。

USB 串口样本格式为：

```text
DATA,timestamp_us,ax_g,ay_g,az_g,gx_dps,gy_dps,gz_dps
```

## 3. 导入并分析 CSV

1. 进入“数据”，点击“导入 CSV 并分析”。
2. 选择 PC 或手机保存的文本/CSV 文件。
3. APK 最多读取 100,000 个有效样本，显示六轴 RMS 和绝对 Peak。
4. APK 使用最多 4,096 点、Hann 窗的基 2 FFT 分析加速度合量，并根据微秒时间戳估算采样率和主频。
5. 点击分享可导出当前分析摘要或实验记录。

支持带 `DATA,` 前缀的八列串口格式，也支持 `timestamp_us` 加六轴数据的七列格式。文件至少需要 16 个有效样本。

## 4. 设置壁纸或 GIF

1. 进入“设置”，展开“屏幕、壁纸与 GIF”。
2. 点击“选择并裁剪”，选择 JPG、PNG、WebP 或 GIF。
3. 在 3:4 编辑器中拖动、双指缩放，确认 240×320 裁剪。
4. 静态图可选择“临时单帧”或“保存壁纸”；GIF 点击“后台播放 GIF”。

原图和原 GIF 不会直接发送给 ESP32。静态壁纸在手机端转为 240×320 RGB565；GIF 则先在手机端一次性抽帧和压缩，写入应用私有目录的 `active.lcg` 播放缓存。ESP32 仅接收当前显示所需的数据，不存储 GIF。

## 5. 为什么 V0.4.0 更流畅

GIF 使用三层节流：

1. 手机端先完成裁剪、抽帧和 RGB332 量化，设备不参与图片解码。
2. 基准帧选择 RGB332 或 RLE332；循环帧在 `delta332`、RLE332 和 RGB332 中选择更小的负载，完全相同的帧跳过。
3. Wi-Fi 目标间隔为 90 ms、最多缓存 240 帧；BLE 目标间隔为 180 ms、最多缓存 120 帧，避免手机内存、链路和 ESP32 同时过载。

`delta332` 不再发送变化矩形中的全部像素，而是记录跳过长度和连续变化像素。实机测试中，一个 10×10 区域内仅一个像素改变时，负载从 RGB332 的 100 字节降为 4 字节。

## 6. 退出 APK 后继续播放

点击播放后，Android 会显示“LabCapsule 动态壁纸”常驻通知。服务持有必要的 CPU 唤醒锁；Wi-Fi 播放还会使用高性能 Wi-Fi 锁。即使在预处理期间划掉界面，当前任务也会完成并自动交给服务；完成后关闭或从最近任务划掉 APK，GIF 仍会继续播放。

可用以下方式停止：

- 在常驻通知中点击“停止”；
- 重新打开 APK，在“设置 → 屏幕、壁纸与 GIF”点击“停止 GIF”；
- Android 系统设置中的“强行停止”会终止整个应用和服务，这是系统行为，应用无法绕过。

如果系统对 LabCapsule 启用了极端省电或后台冻结，建议在系统电池设置中允许后台运行。BLE 播放会在断线后每 2 秒尝试重连；Wi-Fi 播放也会在网络错误后重试。

## 7. 屏幕镜像的边界

APK 的 240×320 预览会同步页面、实验状态、I²C、背光和 HUD，比例与实体屏幕一致。ST7789 当前使用只写 SPI，设备无法读回面板真实像素，因此这属于“状态驱动的同构镜像”，不是视频采集或显存回读。

## 8. 当前硬件提示

COM8 实机的 I²C 地址 `0x68` 能响应，但读取到 `WHO_AM_I=0x70`，与标准 MPU6050 常见标识不一致。正式进行定量六轴实验前，请确认传感器模块实际型号、焊接和供电。
