# LabCapsule V0.9.0 网络形象指南

V0.9.0 把 AI 桌宠从单一内置矢量角色扩展为“内置形象 + 网络 PNG/JPG/WebP/GIF”。网络文件只作为图片解码，不获得脚本、插件、系统命令或设备控制权限。下载、校验、动画解码与缩放都由电脑承担；ESP32-S3 不参与网络形象渲染。

## 一、普通用户操作

1. 打开 Windows `LabCapsule Studio`，进入“AI 桌宠”。
2. 点击“网络形象库 / URL”。
3. 推荐先从 DiceBear CC0 预设中选择风格，修改“角色种子”，点击“生成并应用”。相同风格与种子会得到稳定的相同形象。
4. 使用其他来源时，粘贴 PNG、JPG、WebP 或 GIF **文件直链**，点击“下载并应用”。网页详情页、SVG、ZIP、VRM 和 Live2D `moc3` 不是图片直链，当前版本不会加载。
5. 点击“显示桌面悬浮宠物”检查桌面形象。GIF 按文件自己的每帧延时播放，最快 33 ms/帧，避免桌面渲染过载。
6. 需要显示到 240×320 设备时，点击“将当前形象送到屏幕工作室”。程序只载入预览，仍需用户检查裁剪/FPS 并点击“处理并上传当前媒体”，不会自动覆盖设备壁纸。
7. 点击“恢复内置矢量形象”可回到胶囊角色并删除当前网络形象缓存。

## 二、可直接使用的通用形象网址

以下四个直链使用 DiceBear HTTP API 10.x，并选择了其官方许可证页列入 CC0 1.0 分组的风格。修改 `seed=` 后的文本即可得到另一个稳定角色：

- Pixel Art：`https://api.dicebear.com/10.x/pixel-art/png?seed=LabCapsule&size=256`
- Lorelei：`https://api.dicebear.com/10.x/lorelei/png?seed=LabCapsule&size=256`
- Thumbs：`https://api.dicebear.com/10.x/thumbs/png?seed=LabCapsule&size=256`
- Shapes：`https://api.dicebear.com/10.x/shapes/png?seed=LabCapsule&size=256`

官方入口：

- [DiceBear 风格目录](https://www.dicebear.com/styles/)
- [DiceBear HTTP API](https://www.dicebear.com/integrations/http-api/)
- [DiceBear 许可证分组](https://www.dicebear.com/licenses/)
- [VRoid Studio](https://vroid.com/en/studio)
- [VRoid Hub](https://hub.vroid.com/en)
- [Live2D 示例模型](https://www.live2d.com/en/learn/sample/)
- [Live2D 示例模型使用条款](https://www.live2d.com/en/learn/sample/model-terms/)

DiceBear 的代码许可证与每个形象风格的美术许可证并不相同，必须以风格所在分组为准。VRoid Hub 与 Live2D 的模型通常有逐模型、逐作者或逐分类条款，不能把整个网站理解为“通用免授权素材库”。V0.9.0 只内置 DiceBear CC0 白名单，不内置第三方人物素材。

## 三、资源与性能策略

```text
HTTPS 图片直链
  → 电脑限流下载（最大 12 MiB）
  → MIME + Pillow 内容识别
  → PNG/JPG/WebP/GIF 白名单
  → 尺寸、像素、帧数、总解码量检查
  → SHA-256 与单份原子缓存
  → 电脑端 RGBA 解码、缩放与 GIF 时间轴
  → 主舞台 / 悬浮舞台
  → 用户显式选择后进入 240×320 媒体管线
```

- 单边最大 2048 px，单帧最多 4,194,304 像素，最多 120 帧，源动画总像素量另设上限。
- 桌面显示前先缩到舞台所需尺寸，不长期保留全分辨率解码帧，动画上限约 30 FPS。
- 缓存只保留当前有效形象和一份元数据。新文件完整下载、解码检查和哈希计算成功后才替换；失败继续使用旧形象。
- 软件退出后形象仍在本地缓存，下次启动自动恢复；不依赖手机后台持续传帧。
- 发送到设备时继续复用 V0.7 的电脑端裁剪、抽帧、RGB332/差分压缩与 LCG 单文件策略，设备只负责校验、保存和播放。

## 四、安全边界

- 公网只接受 HTTPS；HTTP 仅允许 `localhost`、`127.0.0.1` 和 `::1`，用于本机测试服务。
- 拒绝带 URL 用户名/密码、非图片响应、未知格式、超限文件和损坏缓存；常见签名参数在界面状态中会隐藏。
- SVG 会携带更复杂的外部引用和渲染面，V0.9.0 不接受；需要时请先在可信软件中导出为 PNG/WebP。
- 下载形象不等于获得版权或肖像授权。用户仍需遵守来源、作者、角色 IP 与用途对应的条款。
- 网络形象不能控制 AI、串口、实验、Wi-Fi、OTA 或本机文件。AI 仍只有结构化回复能力。

## 五、V0.9.0 验证记录

- 本机模拟服务器：PNG、两帧 GIF、HTTP 重定向、HTML 伪装响应、超大 `Content-Length`、哈希篡改、失败保留旧缓存均通过。
- 真实公网：`pixel-art` 直链返回 256×256 PNG、4,037 B，SHA-256 为 `65de5618e2fbf1df4e2ae32d2421d3c91ae6d73a18217f746a19f3430ba56630`，下载和解码通过。该值只对应测试种子 `LabCapsule-V09-Live-Test`；服务端未来重新生成素材时文件哈希可能变化。
- GUI：主舞台、悬浮层、形象库窗口、恢复矢量形象和载入屏幕工作室通过自动化冒烟测试。
- 全部桌面单元/集成测试继续覆盖实验数据校验、图表峰值保留、AI Endpoint 与秘密脱敏。

本版本没有修改固件协议、分区或 Android APK，继续兼容 V0.7.0 固件和 APK。
