# LabCapsule V1.1 AI 测量工作台使用指南

V1.1 将 Android 客户端收敛为“首页 / 数据 / 桌面 / 设置”四个入口。首页只负责 Hiyori 形象和自然语言对话；连接、Live2D、AI、标定、网络、媒体与固件等高级功能全部移到默认折叠的设置页。

## 1. 首次连接

1. 手机保持连接正常有互联网的 Wi-Fi，不要连接 LabCapsule 的无网络恢复热点。
2. 打开任意页面。若设备断开，页面顶部会优先显示连接方式和连接按钮。
3. 只有 5 GHz Wi-Fi 时选择 `Bluetooth LE`，点击“扫描并连接 BLE”。ESP32-S3 不支持纯 5 GHz，但 BLE 测量、I²C 扫描、媒体和 OTA 不受影响。
4. 有 2.4 GHz 网络时，也可先用 BLE 配网，再使用状态中的非 `0.0.0.0` 地址切换到局域网。
5. 连接成功后，四个页面顶部均显示实际链路；无需进入开发界面查找原始 JSON。

## 2. 用一句话开始实验

在首页输入：

```text
马上帮我测试10秒的桌面震动情况
```

APK 会在本地完成以下动作，不把硬件控制权交给云端模型：

1. 将请求识别为运动/振动测量并选择 MPU6050。
2. 提取时长；未写采样率时使用 200 Hz，支持在句子中写“100 Hz”。
3. 先扫描 I²C，再下发带 `sensor=mpu6050` 的 Experiment Protocol。
4. 自动进入“数据”页并实时绘制 AX、AY、AZ。
5. BLE 模式直接保存应用私有 CSV；局域网模式在设备结束本地记录后自动回传。
6. 完成后本地计算六轴 RMS、绝对峰值与加速度合量主频，再由已配置的 AI 解释实验意义。

断线时不会伪造实验结果或静默失败：首页会明确要求先连接，顶部连接操作保持可见。

## 3. 查看与导出曲线

“数据”页的当前实验图表支持：

- 双指缩放时间范围；
- 单指左右拖动；
- 点击任意曲线位置，查看最近测量点的时间、AX/AY/AZ（g）和 GX/GY/GZ（°/s）；
- 导出当前图表为 PNG；
- 导出对应原始 CSV；
- 对当前数据继续发起 AI 分析。

历史记录按日期默认折叠。搜索框支持名称、日期和分析结论的包含匹配与顺序模糊匹配；每条记录均可重新载入曲线、分析或导出。

## 4. 通过对话标定 MPU6050

先完成一次短测量，使 APK 获得当前原始读数，然后在首页说：

```text
将 AX 当前真实值标定为 0
```

APK 会保存 `offset = 当前原始值 - 真实值`，后续统一使用：

```text
corrected = (raw - offset) × scale
```

支持 AX、AY、AZ、GX、GY、GZ；中文“加速度 X 轴”或“角速度 X 轴”也可识别。标定值保存在 APK 私有偏好中，不写入 ESP32，因此可以按手机/用户维护独立配置。CSV、曲线和分析使用同一份修正数据。

若需要清除，在“设置”搜索“标定”，展开“实验与传感器标定”，点击“清除全部 MPU6050 标定”。

## 5. 分析已有数据

在首页输入：

```text
分析当前测得数据所代表的桌面震动情况
```

APK 会先读取最近 CSV 并本地计算，计算成功后才把指标与问题交给 AI。没有 API、没有网络或 AI 服务失败时，原始 CSV、曲线和本地 RMS/Peak/FFT 结果仍然可用。

## 6. 设置与搜索

设置页所有分组默认折叠，包括：

- AI 模型服务；
- Live2D 角色；
- 实验与传感器标定；
- 设备与连接；
- 外部 Wi-Fi 与远程连接；
- 本地记忆与数据同步；
- 屏幕、壁纸与 GIF；
- 固件与维护；
- 自动更新；
- 关于与使用说明。

直接搜索 `Live2D`、`API Key`、`Wi-Fi`、`标定`、`亮度` 等关键词，匹配分组会自动展开；清空搜索后恢复全部折叠。

## 7. 本地优先与私有仓库同步

对话、记忆、实验索引和 CSV 先保存在 APK 私有空间。需要跨设备管理时：

1. 创建用户自己的 GitHub 私有仓库。
2. 创建只授予该仓库 Contents 读写权限的细粒度 Token。
3. 在“设置 → 本地记忆与数据同步”填写 `owner/repository`、分支和 Token。
4. 开启每 15 分钟同步，或点击“立即同步”。

仓库路径：

```text
memory/devices/<deviceId>/snapshot.json
data/devices/<deviceId>/index.json
data/devices/<deviceId>/<yyyy-MM-dd>/<experimentId>.csv
```

标定配置也写入对应硬件 ID 的私有记忆快照：同一台 LabCapsule 在另一台已授权手机上会选择更新时间较新的 MPU6050 标定；清除标定同样会同步，避免旧偏移复活。

仅允许私有仓库。API Key、GitHub Token、Wi-Fi 与 MQTT 密码不会上传。为避免 Android 内存压力，单个超过 8 MiB 的 CSV 暂留本机并在索引中标记，后续应接入对象存储或 Git LFS 大文件后端。

## 8. Live2D 与桌面控制

Live2D 导入位于“设置 → Live2D 角色”。选择包含 `model3.json`、moc3、纹理和动作的完整文件夹；模型只复制到 APK 私有目录，不进入公共仓库。首页只展示当前统一角色与对话。

“桌面”页专门负责 240×320 设备界面、壁纸/GIF、页面遥控与状态监看，不再与实验数据或 AI 配置混放。

## 9. 当前边界

- ESP32-S3 只能接入 2.4 GHz Wi-Fi；纯 5 GHz 环境请使用 BLE 或 USB。
- APK 当前标定是手机侧软件标定；更换手机时应通过私有记忆/数据仓库管理标定记录，或重新标定。
- 公共 GitHub 仓库不会接收用户记忆、Live2D 模型、密钥或实验 CSV。
- APK 使用开发签名；商业发行前必须改用正式签名密钥、隐私政策和正式更新签名链。
