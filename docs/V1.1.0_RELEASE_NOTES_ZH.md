# LabCapsule Android V1.1.0 Alpha

本次发布把 Android 客户端升级为 AI 测量工作台。Windows Studio 与 ESP32 固件继续使用 V1.0.0；协议保持兼容，已运行 V1.0.0-alpha 的 COM8 不需要重新烧录。

## 主要更新

- 导航精简为“首页 / 数据 / 桌面 / 设置”。
- 首页只保留统一 Hiyori Live2D 形象和 AI 对话。
- 自然语言直接触发 MPU6050 测量，例如“马上帮我测试 10 秒的桌面震动情况”。
- BLE 实时采集与局域网离线回传统一进入 CSV、曲线、历史和 AI 分析流程。
- 数据页支持实时 AX/AY/AZ、双指缩放、横向拖动、逐点六轴读数、PNG/CSV 导出。
- 历史数据按日期折叠，支持名称、日期和结论模糊搜索。
- 支持自然语言单轴标定，例如“将 AX 当前真实值标定为 0”。
- AI 可分析最近真实 CSV；AI 不可用时仍保留本地 RMS、Peak、FFT 与主频结果。
- Live2D、AI、连接、标定、屏幕、网络、同步与固件全部移入默认折叠的设置，并支持设置搜索。
- 四个页面都有连接状态；断线时优先显示 BLE/局域网连接操作。
- 对话、记忆、标定和实验数据本地优先；联网后可周期同步到用户私有 GitHub 仓库。

## 安装

下载并安装 `LabCapsule-1.1.0.apk`。Android 可能要求允许“安装未知应用”；从旧开发版升级时必须使用同一开发签名。若签名不一致，先导出必要数据再卸载旧版。

只有 5 GHz Wi-Fi 时请直接使用 BLE，不要让手机连接 LabCapsule 的无网络恢复热点。ESP32-S3 不能加入纯 5 GHz 网络，出现 `staConnected=false / staIp=0.0.0.0` 属于硬件能力边界。
