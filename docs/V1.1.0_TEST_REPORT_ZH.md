Android V1.1.0 源码构建成功，63/63 Python 自动化回归通过，APK v2/v3 签名通过，版本元数据正确。COM8 只读兼容测试通过，确认当前 V1.0.0-alpha 固件仍提供 V1.1 APK 所需的 BLE/USB 设备身份、MPU6050、网络状态、离线数据与桌宠协议。

## Android 真机待验收

安装 APK 后按以下顺序验证：

1. 四个页面顶部均显示连接卡，BLE 连接后连接按钮折叠。
2. 首页只显示 Live2D 与对话，不显示 API、导入、网络或固件配置。
3. 输入“马上帮我测试10秒的桌面震动情况”，确认自动进入数据页并开始增长曲线。
4. 曲线支持双指缩放、单指平移，点击后显示六轴值。
5. 完成后导出 PNG 与 CSV，并输入“分析当前测得数据所代表的桌面震动情况”。
6. 完成短测量后输入“将 AX 当前真实值标定为 0”，再测量确认 AX 使用回正值。
7. 设置搜索 `Live2D`、`AI`、`标定`、`Wi-Fi` 和 `亮度`，确认只显示并展开匹配分组。
8. 配置测试私有仓库后点“立即同步”，确认 `memory/devices/<deviceId>` 与 `data/devices/<deviceId>` 均出现内容。

若没有配置 AI Key，第 3、4、6 项仍应完整工作；第 5 项保留本地 RMS/Peak/FFT，并明确提示 AI 服务未配置。
