# LabCapsule V1.2.0 Alpha 发布说明

V1.2.0 将 Android 与 Windows 的 Hiyori 管理升级为可缓存、可局部替换的私有完整角色卡，并增加安全的手机—Studio—Claude 协同。固件协议没有变化，不需要因为本次 APK/EXE 更新重新烧录 ESP32。

## 新功能

- APK 更新显示真实下载字节、百分比和状态，应用重启后恢复追踪。
- 首页支持多会话、新会话、内容标题、折叠历史、模糊搜索和自动定位；用户/AI 气泡有明确视觉区分。
- 完整角色卡包含 Live2D、人设、180×240 静态预览和可选语音包。
- PC/Android 共用私有仓库 `rolecards/index.json` 与 `labcapsule-rolecards-v1` Release 资产；大文件流式传输，本机按 SHA-256 缓存。
- 两端支持勾选只替换形象、人设或语音包。
- Studio 增加默认关闭的手机桥；一次性配对后，手机可读电脑/设备状态，并将复杂问题转给受限 Claude 后读取回复。
- 新增角色卡 JSON Schema、手机桥测试、角色卡打包/路径逃逸/大小限制测试。

## 安全说明

- 角色卡与记忆同步只允许私有仓库。
- GitHub/API/桥接 Token 不进入仓库，分别由 DPAPI 或 Android Keystore 保存。
- 角色卡下载后必须通过 SHA-256、ZIP 路径、入口文件、数量和大小检查。
- 手机桥不提供 Shell、任意文件或自动设备写权限。可能改变数据、网络、固件或实验状态的操作仍要求本地确认。
- Live2D 资产权利和 Cubism SDK 许可由用户负责；LabCapsule 不把用户模型打入公共 APK/EXE。
