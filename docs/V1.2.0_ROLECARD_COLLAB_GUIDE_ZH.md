# LabCapsule V1.2 角色卡与手机电脑协同指南

V1.2 在 V1.1 的 AI 测量、曲线、标定、数据和设备桌面基础上，增加多会话、更新进度、私有角色卡双端同步，以及明确授权的手机—Studio—Claude 桥。默认语言仍为简体中文。

## 一、安装和更新 APK

1. 在 APK 四个页面顶部确认设备连接状态；更新 APK 不要求连接 ESP32。
2. 打开“设置”，搜索“自动更新”，展开后点击“检查更新”。
3. 发现新版本后点击“下载新版 APK”。页面会显示等待、已下载字节、总字节和百分比；退出后再次打开应用会继续显示同一系统下载任务。
4. 完成后点系统下载通知安装。Android 仍会要求用户确认“安装未知应用”；应用不会静默安装。

## 二、对话管理

1. 首页只保留 Hiyori 舞台、连接状态和对话。
2. 点“新对话”创建空会话。发送第一条消息后，会话标题由这条用户消息自动生成。
3. 当前会话展开，过往会话折叠；点击标题可切换。
4. 在搜索框输入任意片段，匹配的会话会展开，页面自动平滑滚到第一个结果。
5. 黄色右侧气泡是用户，深色左侧气泡是 Hiyori。每个会话最多保存 80 条消息，本机最多保留 30 个会话。

## 三、配置私有仓库

PC 和 APK 必须填写同一个私有 GitHub 仓库、分支和细粒度 Token。Token 至少需要该私有仓库 Contents 读写与 Releases 读写权限。角色和记忆含个人数据，程序会拒绝公开仓库。

- Android：设置 → 本地记忆与数据同步。
- Windows：设置 → 角色与 AI 设置 → 跨设备私有记忆。
- Token 分别由 Android Keystore 和 Windows DPAPI 保护，不上传仓库。

## 四、创建完整角色卡

Windows 推荐流程：

1. 打开桌宠管理，选择并应用现有 Hiyori Live2D 文件夹。V1.2 不重新创作模型；可继续使用 `<Live2D模型目录>` 中已确认可用的模型。
2. 在设置选择一张静态预览；图片会在电脑端缩放到 180×240 JPEG。可选一个语音文件或语音包。
3. 编辑并保存 AI 人设。
4. 点击“上传当前完整角色卡”。Studio 流式打包、计算 SHA-256，并上传到私有仓库的 `labcapsule-rolecards-v1` Release；`rolecards/index.json` 只保存小型索引与静态预览。

Android 也可以先导入完整 Live2D 文件夹，再在“设置 → 角色卡与双端同步”选择预览、可选语音包和人设，最后上传。

## 五、选择和局部替换角色卡

1. Android 展开“角色卡与双端同步”，或 Windows 点击“同步并选择私有仓库角色卡”。
2. 横向滚动查看静态预览。
3. 勾选需要替换的“形象 / 人设 / 语音包”。未勾选部分保持当前值。
4. 点击角色卡。完整 ZIP 只在本机没有对应 SHA-256 缓存时下载；页面显示进度。
5. 下载后先校验 SHA-256，再检查 ZIP 路径、文件数量、清单和大小，最后使用临时目录切换。失败时保留旧角色。

模型和语音包不进入 ESP32。手机或电脑负责运行 Live2D；实体 240×320 屏幕显示同一角色 ID 的本地代理、动作和回答气泡。

## 六、手机访问电脑和 Claude

1. 电脑与手机连接同一个正常联网的局域网；不要让电脑或 Codex 切换到 LabCapsule 无网络恢复热点。
2. Windows Studio → 设置 → “开启手机桥并生成配对码”。记录局域网地址和 6 位码；首次开启时允许 Windows 防火墙的“专用网络”访问。
3. Android → 设置 → 电脑与 Claude 权限。填写 Studio 地址和当前 6 位码，点击“申请电脑权限”，阅读授权范围后确认。
4. 配对码 10 分钟有效且成功使用后立即轮换。手机 Token 保存于 Android Keystore；电脑只保存 Token 的 SHA-256。
5. 在首页问“电脑现在怎么样”，APK 会读取 CPU、内存、磁盘和已连接 LabCapsule 的状态。
6. 问“让电脑中的 Claude 全面分析当前实验”，Studio 使用现有受限 Claude 桥处理，并把最终文本回传到手机。

安全边界：V1.2 手机桥只开放 `computer.status`、`labcapsule.context` 和 `claude.delegate`，不开放远程 Shell、任意文件读取或未经确认的设备写操作。涉及固件、网络、删除数据、开始或中止实验的动作仍需用户在相应设备界面确认。

## 七、常见问题

- `staConnected=false / staIp=0.0.0.0`：ESP32-S3 只支持 2.4 GHz。只有 5 GHz 时继续用 USB 或 BLE；手机和电脑仍可使用自身正常联网 Wi-Fi。
- 角色卡不显示：确认仓库是 private、Token 同时有 Contents 和 Releases 权限，并点击手动刷新。
- Live2D 下载后不运行：确认已阅读 Live2D/Cubism 条款；角色卡只同步用户有权使用的模型，不改变模型许可。
- 手机无法访问 Studio：确认地址使用电脑真实局域网 IP、端口 8765、防火墙允许专用网络，并且 Studio 手机桥仍为开启状态。
- Claude 无回答：确认电脑已安装 Claude Code；桥接失败不会影响本地实验、状态读取和已缓存角色。
