## COM8 状态

Windows 设备枚举确认 `USB-Enhanced-SERIAL CH343 (COM8)` 正常存在。最终只读验收脚本未能独占 COM8，因为当时已有三个用户运行中的 `LabCapsule-Studio-0.10.0` 进程占用端口；为避免关闭用户窗口或破坏未保存状态，本次没有强制终止它们。此前 V1.1 发布对同一硬件 `lc-000000000000` 的 PING、IDENTITY、STATUS、NETWORK、SENSORS、PET 和 MPU6050 0x68 已通过，且 V1.2 未修改固件协议。

需要复测时，先正常关闭旧 Studio 窗口，再运行：

```powershell
python tests/manual_com8_v1_acceptance.py --port COM8
```
