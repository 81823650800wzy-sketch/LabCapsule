# LabCapsule V1.3.0 Alpha 发布说明

V1.3.0 重点完成自然语言到真实硬件实验的受控闭环：AI 负责理解和规划，本地代码负责验证与执行，设备回包负责确认是否真正开始。

## 主要变化

- Android 新增真实 AI 实验规划 JSON、传感器/参数/参考模式白名单及透明离线回退。
- 新增 I²C 新鲜扫描门禁、精确传输通道检查和设备 START 成功确认。
- 数据页新增实时用时、实验进度、当前/预计样本及终止按钮。
- 正常完成、用户终止、传输中断、设备错误和分析失败分别记录，不再混用成功状态。
- Studio 手机桥新增 `/v1/research`，只允许 Claude WebSearch/WebFetch 查找实验参考。
- 本次没有改变 ESP32 通信协议；固件新增 I²C 互斥、读取重试、有限自动恢复和异常离线封存，现有 START、ABORT、SENSORS、BLE 实时数据及 HTTP 离线同步接口保持兼容。

完整操作见 [V1.3 AI 真实实验使用指南](V1.3.0_AI_EXPERIMENT_GUIDE_ZH.md)。
实测证据见 [V1.3 测试报告](V1.3.0_TEST_REPORT_ZH.md)。
